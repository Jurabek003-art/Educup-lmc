# EduCenter LMS — Telegram Mini App

Boshlang‘ich ishlaydigan frontend MVP.

## Ishga tushirish
1. Repository yarating.
2. Ushbu ZIP ichidagi fayllarni repository'ga yuklang.
3. GitHub Pages'ni Settings → Pages orqali yoqing.
4. `index.html` root papkada qolishi kerak.

## Hozir ishlaydi
- Responsive admin dashboard
- Light/Dark mode
- Talabalar jadvali
- Global qidiruv
- Dashboard statistika UI
- Davomat/To‘lov/Guruhlar/Hisobotlar demo modullari
- Telegram Web Apps JS ulanishi
- Mobile bottom navigation

## Keyingi bosqich
Supabase database, authentication, RBAC, Teacher/Student real kabinetlari, QR attendance va Telegram Bot.
